# Graffiti.pc #133: a private-crossing obstruction

This is a partial result, not a proof of the full conjecture. Suppose a graph has no ordinary four-cycle and no induced path on nine vertices. In it, take an induced seven-cycle and two independent control vertices in either of the two normalized contact patterns in the theorem. Suppose each of the nine core vertices has an exterior vertex adjacent to it and to no other core vertex, called a private witness. Then a control's private witness cannot be adjacent to a cycle vertex's private witness. The conclusion holds for every choice of those two witnesses, without restrictions on the remaining witness edges.

The exact patterns and premises are in [`canonical_private_witnesses_do_not_cross`](src/NestedCorePrivateCrossLift133.lean). The lift selects and labels nine distinct exterior witnesses and maps a hypothetical crossing to one of 28 normalized cases. Each finite branch ends in either a four-cycle or an induced nine-vertex path. The [checker soundness proof](src/NestedCorePrivateCrossKernel133.lean) verifies the witness against arbitrary unresolved adjacency bits, and Lean checks the 28 trees with `decide` in [the table](src/NestedCorePrivateCrossRows133.lean). All four modules replayed against the pinned project dependencies with warnings as errors and standard axioms only.

Run `bash graffiti-133-private-cross/replay.sh` from the repository root in a Lean 4.19.0 / Mathlib 4.19.0 environment (for example `lake env bash /path/to/maths/graffiti-133-private-cross/replay.sh` from a prepared Mathlib checkout).
